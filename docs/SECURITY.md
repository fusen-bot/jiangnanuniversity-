# 安全设计

## 控制措施

- 认证：PBKDF2-HMAC-SHA256（独立随机盐、600,000次迭代）与短期签名令牌。
- 授权：后端RBAC是唯一授权依据；前端菜单隐藏只改善体验。
- 会话：HttpOnly + SameSite Cookie，写请求使用双重Cookie CSRF校验。
- 数据：身份证、税号、邮箱对只读角色脱敏；密钥只来自环境变量。
- 文件：扩展名、MIME、大小三重限制；随机存储名；下载只按数据库ID解析。
- 集成：期刊网关只允许配置的HTTPS主机且不自动跟随重定向，降低SSRF风险。
- AI：输入注入检测、上下文隔离、只读工具、输出只作建议、写操作二次确认。
- 审计：登录、导入、修订、复核、提交、审批、导出、下载和AI确认均记录事件。
- 仓库防泄漏：CI阻止常见财务源文件、数据库、压缩包、密钥和身份证模式进入Git历史。

## 数据分级

- 公开：产品文档、模拟SOP。
- 内部：任务、评论、批次状态。
- 机密：财务金额、发票和核销信息。
- 受限：身份证、税号、账号凭证、API Key。

生产环境还应配置HTTPS、反向代理限流、数据库加密备份、集中日志告警、密钥轮换和机构级身份认证。
