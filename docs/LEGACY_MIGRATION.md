# 旧版迁移映射

| 原型能力 | 新版位置 | 改造结果 |
|---|---|---|
| Flask路由 | FastAPI `/api/v1` | 版本化契约、Pydantic校验、RBAC |
| Excel直接读写 | PostgreSQL + 导入/导出服务 | 事务、唯一约束、版本与审计 |
| 审稿费脚本 | `services/rules.py` | 独立规则与单元测试 |
| 版面费复选框 | 版面费记录 + 批次状态 | 业务状态与审批分离 |
| 稿费爬虫 | `JournalGateway` + Celery | HTTPS主机限制、重试、失败状态 |
| PDF作者提取 | PDF异步任务 | 结构化结果、人工修订、版本控制 |
| Todo | 工作流任务 | 可关联批次、异常、负责人 |
| 便签 | 评论 | 有创建人和时间，进入业务上下文 |
| 打开本地文件夹 | 文件中心 | 适配服务器和Docker部署 |
| 通用AI聊天 | AI业务副驾 | 制度依据、授权工具、确认与审计 |

旧目录暂不删除，用于核对原始业务算法与用户已有修改。迁移验收完成后再单独决定归档策略。
