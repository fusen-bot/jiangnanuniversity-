# AI工程

## 处理链路

`输入安全检测 → 制度检索 → 授权业务工具 → DeepSeek → 输出记录 → 人工确认写操作`

- Prompt 使用版本号 `business-copilot-v1`，约束模型只能依据提供内容回答。
- 知识片段保留标题和来源；回答返回引用，不把文档中的指令视为系统指令。
- 当前只读工具为批次摘要，返回状态、记录数和开放异常数。
- “创建任务”只生成建议；确认接口校验建议归属和幂等性后再写入。
- 记录模型、Prompt版本、Token、延迟、来源和工具摘要，但不记录API Key。
- 无 DeepSeek Key 时可启用 Fake AI，用于CI和完整产品流程验证。

## 固定评测集

评测至少覆盖：制度问答有引用、无依据时不编造、异常摘要参数正确、跨角色越权拒绝、提示注入拒绝、模型不能声称完成审批、建议未经确认不产生任务、重复确认被拒绝。

真实模型评测不进入普通CI，避免成本和不确定性；发布前在固定数据集上单独执行并记录准确率、引用命中率、工具成功率、延迟和Token消耗。
